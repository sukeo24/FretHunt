# FretHunt

**ギターの指板を、もっと直感的に理解する。**

FretHuntは、ギターの指板上にある音名や音程の位置関係を、視覚的・直感的に学習するために開発したWebアプリです。

HTML・CSS・JavaScriptを使用して個人開発しました。

## 開発背景

ギターを始めた頃、指板上の音名を効率よく覚えたいと考えていました。

既存の学習アプリも試しましたが、実際に自分が弾いているギターと見た目が異なるため、アプリ上で覚えた位置関係を実際の指板に結びつけにくいと感じました。

そこで、**普段使っているギターに近い見た目で学習できるツール**を自作することにしました。

単に音名を表示するだけでなく、指板の材質やポジションマーク、ギターのモデルなどを変更できるようにしています。

## 主な機能

- **自由学習モード**：指板上の音名・度数・階名を表示
- **音名クイズ**：指定された弦・フレットの音名を回答
- **オクターブ探索**：同じ音名を持つ別のポジションを探す
- **完全5度クイズ**：指定された音の完全5度上の音名を回答
- **キー変更**：12キーに対応
- **スケール表示**：ダイアトニック音のみの表示に対応
- **ギターのカスタマイズ**：モデル2種類、指板材3種類、インレイ4種類
- **音声再生**：Tone.jsによる音の合成・再生

## 技術スタック

- **言語**：HTML / CSS / JavaScript
- **描画**：HTML Canvas API
- **音声処理**：Tone.js
- **公開**：GitHub Pages

## 開発で工夫したこと

### 実際のギターに近い指板の描画

Canvas APIを使用し、指板・フレット・弦・ポジションマーク・ピックアップなどを描画しました。

フレット間隔は高音側ほど狭くなるように計算し、実際のギターに近い形状を再現しています。

また、指板材やギターのモデルに応じて、色・木目・インレイ・ピックアップの形状が変化するよう実装しました。

### 音楽理論に基づく学習機能

各弦の開放弦の音名とフレット番号から、半音単位で音名を計算しています。

この仕組みを利用して、キーに応じたダイアトニック音の抽出、度数・階名の表示、完全5度の計算などを実装しました。

### 視覚的なフィードバック

クイズへの回答後、正解の音が存在するポジションを指板上に表示することで、音名だけでなく位置関係も確認できるようにしました。

## 開発を通じて学んだこと

ギターを始めて間もない2025年春頃に開発した個人プロジェクトです。大学の授業中にこっそり開発していました。

既存のアプリでは満たせなかった自分自身の学習上の課題を出発点として、UI設計・Canvasによる描画・音楽理論に基づくロジックの実装を経験しました。

特に、見た目は単なる装飾ではなく、学習内容を実際の楽器と結びつけるための重要な要素だと考え、指板の再現に力を入れました。

現在は開発を一旦区切っていますが、ギターや音楽理論への理解が深まった今、さらに発展させられる可能性を感じています。
